# Project Guidelines

A collection of user styles for [Stylus](https://addons.mozilla.org/en-US/firefox/addon/styl-us/) that enhance the appearance and usability of web browsing.

## Overview

1. `src/` directory: Contains all user style source files
2. `pages/` directory: Web-based distribution
   - Contains the installation page with download links
   - Generated by `npm run build:page`

### Key Tooling

- ESLint: Code linting (configured via `eslint.config.mjs`)
- Stylelint: CSS linting (configured via `stylelint.config.mjs`)

## Coding Conventions

Project-specific coding rules are maintained in:

- [skill.md](.agents/skills/userstyles/skill.md)

## File Naming Conventions

- File names must end with `.user.css`
- Names should be descriptive and indicate the site or functionality
- Use Title Case for readability

## When Adding New User Styles

1. Create the file in `src/` with `.user.css` extension
2. Add Stylus metadata with proper @match patterns
3. Run `npm run lint` to format css
